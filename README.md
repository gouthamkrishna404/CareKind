# CareKind

Static marketing site for CareKind homecare services (carekind.ca).

## Development

Source lives in `src/`; the root-level `.html`/`.css`/`.js` files are generated build output committed for GitHub Pages.

```
npm install
npm run build   # regenerate the root files from src/
npm run watch   # rebuild on change
```

See `CLAUDE.md` for the full architecture breakdown.
